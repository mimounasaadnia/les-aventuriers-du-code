# 🚀 Les Aventuriers du Code

Formation ludique pour initier ma fille (11 ans, 6e) à la logique de la programmation, module par module.

## Objectif

Pas d'apprentissage rébarbatif : on découvre la logique informatique à travers des petits défis, avant de passer à des outils comme Scratch.

## Comment c'est organisé

- `docs/` — la vision du projet et les personnages (Byte, Glitch...)
- `module-01-cest-quoi-un-ordi/`, `module-02-...`, etc. — un dossier par module, chacun avec :
  - `lecon.md` : l'explication + un exemple
  - `exercices.md` : les exercices et défis à faire

## Progression prévue

1. C'est quoi un ordinateur ?
2. Les algorithmes
3. Les séquences
4. Les variables
5. Les calculs
6. Les conditions
7. Les boucles
8. Les fonctions
9. Les bugs
10. Découverte de Scratch
11. Créer un jeu
12. Mon premier projet

On avance module par module, en testant avec elle avant de passer à la suite.
