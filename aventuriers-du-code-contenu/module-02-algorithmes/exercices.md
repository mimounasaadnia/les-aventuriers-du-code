## 🐛 Trouve le bug
Glitch a écrit cet algorithme pour se laver les mains, mais quelque chose ne va pas :

```
Début
  Ouvrir le robinet
  Se sécher les mains
  Mettre du savon
Fin
```

Quel est le problème ? Réécris l'algorithme dans le bon ordre.

---
*Corrigé parent : dans le bug, l'ordre est incohérent (se sécher avant de mettre le savon). Bon ordre attendu : ouvrir le robinet → mettre du savon → se frotter les mains → rincer → fermer le robinet → se sécher. C'est l'occasion de montrer que dans un algorithme, l'ordre des étapes change complètement le résultat.*
