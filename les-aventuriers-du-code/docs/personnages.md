# Personnages

Deux personnages simples pour accompagner les leçons, pas plus pour l'instant — on enrichira seulement si ça plaît à l'usage.

## Byte 🤖
Petit robot curieux qui explique les leçons. Toujours positif, pose des questions pour faire réfléchir plutôt que de donner la réponse tout de suite.

*Phrase type :* "Attends, avant de foncer... tu es sûre de l'ordre des étapes ?"

## Glitch 👾
Petit personnage maladroit qui fait exprès des erreurs (bugs) dans les exercices, que l'enfant doit trouver et corriger. Sert de ressort ludique pour le module sur les bugs, mais peut apparaître ailleurs.

*Phrase type :* "Oups, j'ai oublié une étape... tu la retrouves ?"

---
*Note : on ajoutera d'autres personnages seulement si le format prend bien avec elle. Pas besoin de construire tout un univers avant d'avoir testé le module 1.*
